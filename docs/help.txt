Object-Oriented Programming

Everything in Ruby is an object.

Example:

name = "Alice"

puts name.length

name is a String object.

Output:

5
Ruby Classes

Example:

class User

  def initialize(name)
    @name = name
  end

  def hello
    puts "Hello #{@name}"
  end

end


user = User.new("Alice")
user.hello

Output:

Hello Alice

Rails Example

Route:

get "/users", to: "users#index"

Controller:

class UsersController < ApplicationController

  def index
    @users = User.all
  end

end

Model:

class User < ApplicationRecord

end

Rails automatically connects the model to the database.

Ruby on Rails Features

Rails provides:

1. Database ORM

Called Active Record.

Instead of writing:

SELECT * FROM users;

you write:

User.all
2. Routing

Example:

get "/login", to: "sessions#new"
3. Authentication

Common libraries:

Devise
OmniAuth
4. Migrations

Database changes are managed with code.

Example:

rails generate migration AddEmailToUsers email:string
